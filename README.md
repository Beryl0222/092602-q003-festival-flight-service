# 节日航班服务包重排

本项目提供节日航班服务包重排的服务端领域基础与重排调度账。面对航班合并、机型更换和旅客改签，系统把航班版本、旅客资格、休息室站点、物料批次、过敏原声明、活动人员资质、装载交接和替代方案连接到同一本事件账上，替代各站点独立改单。

## 核心语义

- **事件账为唯一事实来源**：所有变更先追加到账（`src/ledger.js`，JSONL 可持久化），状态由重放事件重建；调度进程重启后自动续跑未完成的迁移与补偿。
- **唯一份额**：每项权益从预留到确认持有唯一可用份额（休息室座位、批次数量、活动人员槽位），确认不二次占用；份额分配固化在事件派生字段中。
- **航班拆并**：只迁移仍可兑现且符合目的地规则的权益；已核销体验保持原事实不参与迁移；无法兑现的登记未兑现责任并释放原份额。
- **幂等与冻结**：同一运行事件编号重放相同载荷不产生新事实；编号相同而载荷不同则冻结相关服务包，冻结事实同样入账。
- **高风险复核**：高风险食品替换须由与提议人不同的角色复核，供应方不能批准自身批次；非高风险替换提出即兑现。
- **旅客账单**：`passengerStatement` 返回最终可领取项目、每次变更依据（事件编号与摘要）、未兑现责任和受影响批次，而不是只给出当前库存总数。

## 目录

- `src/ledger.js` 追加式事件账：按事件编号幂等，载荷摘要冲突即拒绝。
- `src/scheduling.js` 重排调度服务：登记、权益生命周期、拆并迁移、替代方案复核、恢复与旅客账单。
- `src/domain.js` 定义已有记录和输入校验。
- `src/repository.js` 保存基础记录。
- `src/service.js` 提供登记、查询与健康检查。
- `contracts/record.json` 说明现有输入契约。
- `contracts/events.json` 说明重排事件契约。
- `data/sample.json` 提供本地冒烟数据。
- `tests/` 覆盖登记、查询、重复编号边界，以及份额占用、拆并迁移、冻结、复核与重启恢复。

## 运行

运行测试：`npm test`

检查源码：`npm run build`

验证样例：`npm run check:sample`

项目只使用 Node.js 内置模块，不需要连接其他运行服务。
