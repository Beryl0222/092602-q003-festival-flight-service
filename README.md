# 节日航班服务包重排

本项目提供节日航班服务包重排的服务端领域基础与事件溯源账本。航班合并、机型更换、旅客改签同时打乱客舱活动与休息室体验时，系统把航班版本、旅客资格、休息室站点、物料批次、过敏原声明、活动人员资质、装载交接和替代方案连接到一本重排账中，保证：

- 每项权益从预留到确认占用唯一可用份额（休息室容量 / 批次数量 / 人员场次），同一批点心不会被重复承诺；
- 航班拆并时只迁移仍可兑现且符合目的地规则的项目，其余转为未兑现责任并自动生成补偿；已核销的体验保持原事实不再迁移；
- 同一 `event_id` 重放幂等不二次占用；编号相同而载荷不同则冻结相关服务包，待人工核查解冻；
- 高风险食品替换需不同角色复核，供应方不能批准自身批次；批次召回或非遗人员取消时，相关权益立即转为未兑现责任，不再显示为可领取；
- 调度进程重启后从事件账（JSONL）恢复，`recover()` 续办未完成的迁移与补偿；
- `passengerStatement()` 返回某位旅客最终可领取的项目、每次变更依据、未兑现责任和受影响批次，而不是只给出当前库存总数。

## 目录

- `src/domain.js` 基础记录、权益状态机、过敏原冲突与载荷指纹等纯函数。
- `src/ledger.js` 追加式事件账：重放去重、同号异载荷冲突检测、JSONL 持久化。
- `src/repository.js` 保存基础记录。
- `src/service.js` 事件入口、状态投影、迁移结算、冻结与复核、恢复与旅客账单。
- `src/cli.js` 本地命令入口。
- `contracts/record.json` 基础登记契约；`contracts/events.json` 事件契约。
- `data/sample.json` 基础冒烟数据；`data/events-sample.json` 样例事件流。
- `tests/` 覆盖登记查询、唯一份额、幂等重放、冲突冻结、拆并迁移、替换复核与重启恢复。

## 运行

运行测试：`npm test`

检查源码：`npm run build`

验证样例：`npm run check:sample`

回放样例事件流：`npm run check:events`（写入 `data/ledger.jsonl`）

查询旅客账单：`node src/cli.js statement P1002`

恢复报告并续办：`node src/cli.js recovery`

项目只使用 Node.js 内置模块，不需要连接其他运行服务。
